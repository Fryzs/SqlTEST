# SqlTEST

Контрольна робота на Windows Forms (.NET Framework), що виконує SQL-запити до локальної бази MySQL і показує результат у таблиці (`DataGridView`).

## Що вміє

- **Пошук книг за автором** — показує, у яких бібліотеках є книги цього автора і скільки примірників (таблиці `books`, `authors`, `book_copies`, `libraries`).
- **Підрахунок ресторанів** — кількість ресторанів заданої категорії в заданому районі (таблиця `restaurants`).

## Запуск

1. Підніміть локальний сервер MySQL з базою `library_db` і потрібними таблицями.
2. Вкажіть свої дані підключення в рядку `connectionstring` у `Кр/Form1.cs`.
3. Відкрийте `Кр.sln` у Visual Studio, відновіть NuGet-пакети (MySql.Data) і натисніть F5.
